## Metric definitions

Let (g_j) be a generated spectrogram with species (y_j), and let (x_i) be a test spectrogram with species (y_i). All MSEs below are pixel MSEs in the shared standardized-logmel domain.

### Generated-to-test

For every generated sample, find the closest test spectrogram of the same species:

\[
\operatorname{MSE}_{G\rightarrow T}
= \frac{1}{M}\sum_{j=1}^{M}
\min_{i:\,y_i=y_j}\operatorname{MSE}(g_j,x_i).
\]

The reported count is therefore 48: one nearest-test distance per generated sample.

### Real-to-real leave-one-out baseline

For every test sample, find the closest *other* test spectrogram of the same species:

\[
\operatorname{MSE}_{T\rightarrow T}
= \frac{1}{N}\sum_{i=1}^{N}
\min_{k\ne i,\,y_k=y_i}\operatorname{MSE}(x_i,x_k).
\]

The reported count is therefore 489: one leave-one-out nearest-neighbor distance per test sample. This is a reference for within-test-set pixel-space proximity, not a matched-pair ground truth.

For both protocols, `mean`, `std`, `median`, `q1`, `q3`, `min`, and `max` are computed over the sample-level nearest-neighbor distances. The generated and real baseline counts differ, so their distribution summaries should not be described as a paired comparison.

## Report-ready wording

The following paragraph can be adapted directly into Section 6.2:

> To compare independently generated samples with the original held-out data without imposing an arbitrary one-to-one pairing, we computed a same-species nearest-neighbor pixel MSE in the standardized-logmel domain. Each of the 48 VAEv3 samples was compared with the closest spectrogram among the 489 held-out test samples of the same species, giving an overall mean MSE of 0.5120 (SD 0.1998; median 0.4501; IQR 0.3878--0.6231). As a real-to-real reference, each test sample was compared with its closest other test sample from the same species, giving a mean leave-one-out MSE of 0.3350 (SD 0.1419; median 0.3185; IQR 0.2368--0.4154). These are unpaired pixel-space proximity measures: a lower value indicates closer arrays in this representation, but nearest-neighbor matching can reward copying or limited diversity and cannot, by itself, establish perceptual or waveform realism.

## Claim boundaries and update checklist

- This comparison is between the existing VAEv3 generated spectrograms and the local held-out test spectrograms.
- The primary MSE uses the shared standardized-logmel domain, not the current classifier-input adapter and not Harvey's current CRNN.
- The test set was opened only after generation and protocol choices were frozen.
- Same-species nearest-neighbor MSE is an unpaired pixel-space diagnostic; it is not a perceptual-realism metric and it can reward copying.
- The real-to-real value is a leave-one-out reference with a different sample count, not a paired baseline.

Do not say:

- that the result uses Harvey's corrected canonical pool;
- that the result measures waveform/audio realism;
- that a lower MSE proves better generation quality;
- that the generated samples were compared in the current CRNN's input domain;
- that the test set was used to fit the posterior bank, tune temperature, select samples, or choose a checkpoint.
